# Очередь к Валентине

Небольшой шуточный сайт-приглашение. Валентина выбирает талон на чай, кофе, кино или доверяет выбор одному из пяти случайных вариантов.

## Входные данные

- Портрет в `assets/valentina.jpg`, предоставленный для этой страницы.
- Ссылка на официальную запись к стоматологу и Telegram username Славы.

## Результат и структура

- `index.html` — разметка страницы и талона.
- `styles.css` — оформление и адаптивная версия.
- `script.js` — выбор варианта и формирование ссылки Telegram с черновиком сообщения.
- `assets/` — портрет и иконка.

Источник правды для текстов и вариантов выбора — `script.js`, для адресов также `script.js`. Telegram открывает черновик; сайт сам ничего не отправляет и не хранит ответы.

## Проверка

В корне проекта запустить `python3 -m http.server 4173`, открыть `http://localhost:4173/`, проверить все варианты, случайный выбор и ссылки. Сайт статический и может публиковаться через GitHub Pages из корня ветки `main`.
